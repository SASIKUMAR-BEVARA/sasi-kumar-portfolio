GLOBAL CLIMATE INSIGHTS

Visualizing 140 Years of Climate Anomalies

Category Data Analytics
Data Toolkit Python, Pandas, NumPy, Tableau
Tech Stack Tableau API, HTML5, CSS Variables, JS
Date Nov 2024

Project Overview

Global Climate Insights is an analytical data mining research dashboard designed to clean, process, and visualize temperature anomalies spanning from 1880 to the present day. By leveraging NASA GISS temperature indices, this project compiles large meteorological datasets to build accessible, storytelling charts.

Using python data parsing pipelines, we scrubbed raw text listings, handled empty cells, normalized regional variance indices, and structured databases for ingestion into interactive dashboards.

Methodology & Analytics

1. Scrape & Wrangle (Python/Pandas)
Imported monthly temperature deviations across global stations. Handled missing data points using linear interpolation, and grouped monthly records into decadal averages for analysis.

2. Trend Analysis & Moving Averages
Calculated 5-year and 10-year rolling moving averages to smooth short-term noise, illustrating a clear long-term upward warming trajectory.

3. Tableau Interactivity Integration
Designed custom dashboard layouts displaying geo-spatial temperature heatmaps alongside global CO2 emission curves to visually examine the correlation.

Interactive Climate Simulator

Explore the temperature anomalies across different regions. Use the dropdown controls to select a **Region** and a **Year Group**, and observe how regional temperature anomalies (measured in °C deviations from the 1951-1980 baseline) have shifted.
