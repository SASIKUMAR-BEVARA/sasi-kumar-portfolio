FOODIE FLEET

Reactive E-Commerce Food Logistics Application

Category Full-Stack Development
Architecture Decoupled REST API
Tech Stack React.js, Django framework, MongoDB NoSQL, CSS Flexbox
Date Jan 2025

Project Overview

Foodie Fleet is a responsive full-stack food delivery application designed to handle high-frequency menu catalogs, real-time cart states, user profile sessions, and transactional orders. The project bridges a decoupled frontend (React.js) with a secure backend application engine (Django) powered by a flexible MongoDB schema.

Rather than relying on rigid database structures, the menu details are served as flexible, query-optimized JSON payloads, reducing server load times and providing page transitions that feel instantaneous for the user.

Architecture & Database Design

1. RESTful JSON Middleware
We designed structured API endpoints in Django. These act as secure channels, authenticating user sessions via Token-based verification, and piping catalogs down to the client React engine.

2. MongoDB Document Models
Utilizing MongoDB database structures lets the menu items have varying schemas (e.g. customizations, side choices, dietary tags) without requiring costly table alterations, keeping the application scalable.

3. Reactive Cart State Management
The shopping cart maintains immediate recalculations entirely client-side using JavaScript state variables. Item counts, delivery estimates, taxes, and vouchers recalculate instantly on card events.

Security & Performance

  • JWT Authentication Securing order histories and dispatch permissions using signed tokens.
  • Debounced Searches Catalog search inputs are debounced to optimize MongoDB request load.
  • Django REST Framework Decoupled serializers validating input values before processing.
